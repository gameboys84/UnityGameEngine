# 启动与进入游戏流程

## 运行入口

目标工程为 `UnityProject1`。在 Unity 2022.3.62f2 打开 `Assets/Launcher/Scenes/Launcher.unity`，点击 Play。启动器自动初始化资源、预加载必要内容，并进入 `Assets/AssetBundle/Scenes/Main.unity`。主场景目前为基础流程验证场景，不含 DeadEmpire 业务玩法。

启动场景为 Build Settings 中第一个启用场景。主场景由 YooAsset 加载，不需要作为内置场景添加。

在 Editor 直接打开 Main 点击 Play 时，如果没有 RootModule，演示入口会先加载 Launcher，再走完整资源初始化流程。这是 Editor 的演示入口补偿；Player 仍从内置 Launcher 开始。UI 操作须在 Play 状态的 Game 视图进行。

## 模块边界

| 目录 | 职责 |
| --- | --- |
| `Assets/Scripts/Launcher` | 主包 `Launcher` 程序集：GameEntry、原生启动界面、启动配置 |
| `Assets/Scripts/Procedure` | 通过 asmref 归属 `Launcher`：TEngine Procedure/FSM 启动流程 |
| `Assets/Scripts/Hotfix/GameCore` | 项目 GameModule 门面；共用实现通过 Ni.GameCore 引用 |
| `Packages/com.ni.gamecore` | Ni 维护的共用 UI、存档、资源引用、实例池与基础工具 |
| `Assets/Scripts/Hotfix/Runtime` | `GameRuntime` 程序集：游戏入口和主场景验证逻辑 |
| `Assets/Launcher` | 随安装包提供的启动场景、启动界面预制体及设置 |
| `Assets/AssetBundle` | YooAsset 管理的主场景、配置和预制体 |

启动器不依赖 GameCore/GameRuntime 类型，进入游戏时按照 TEngineNi 的方式反射调用 `GameRuntime.GameApp.Entrance(object[])`。游戏层负责 UI 模块初始化。原生启动界面独立于资源包，资源初始化失败时仍能显示重试按钮。

## 流程

`ProcedureLaunch → ProcedureInitResources → ProcedureStartGame`

资源阶段依次执行：初始化指定包 → 查询包版本 → 更新资源清单 → 下载缺失文件（无文件则跳过）→ 预加载文本资源。每一步检查失败状态，并更新启动界面的进度和提示；失败后停留在当前阶段，点击重试。重复重试不重复初始化已经成功初始化的包。

进入游戏阶段：解析游戏入口 → 通过 TEngine SceneModule 异步加载 Main → 调用 GameApp.Entrance → 确认入口正常返回 → 释放预加载引用 → 隐藏原生启动界面。主场景显示从资源包加载的文本及验证模型。

I/O 使用 UniTask。FSM 在 Update 中推进状态，异步任务只汇报完成或失败。生命周期结束时取消等待、停止下载并清理流程。进度为阶段加权进度，不表示下载字节比例；下载阶段内部使用真实字节比例。

## 配置与发布范围

在 `Assets/Launcher/Settings/StartupSettings.asset` 设置包名、编辑器模式、玩家模式、资源服务器地址、主场景、预加载内容和游戏入口。编辑器默认使用 EditorSimulateMode，独立于全局 EditorPrefs；玩家默认 OfflinePlayMode。联机资源更新可选 HostPlayMode，需要有效的资源服务器和已发布的包。

`DefaultPackage` 采集 `Assets/AssetBundle`；`FoundationValidation` 保留原有基础测试用途。完整资源路径可以用作定位地址，避免业务代码依赖文件名地址。当前采集规则仍会生成文件名地址，因此新增不同类型资源也需要避免同名。

生成工具：`TEngine/Startup/Create Startup Assets` 仅用于首次建立场景，不覆盖已有场景。后续直接编辑现有场景/预制体。启动界面目前使用英文和 Unity 内置字体，多语言方案尚未定案。

当前验证目标是编辑器中的真实资源及场景链路。离线安装包需要通过 YooAsset 构建并复制内置资源；Host 下载需要资源服务验证；移动设备和小程序需要独立构建验收。此流程保留游戏程序集入口边界，但尚未加载 HybridCLR DLL/AOT 元数据，不代表代码热更新已验收。


## 共用框架包

2026-10-26 起，资源、流程和场景实现来自 com.ni.tengine；共用 UI/存档/池/列表来自 com.ni.gamecore（Ni.GameCore 程序集），项目 GameCore 保留 GameModule 门面。当前需同级 Ni/FrameworkPackages 本地源码；启动场景、StartupSettings、TEngine Settings、YooAsset 采集配置和 Demo 资产仍由本工程管理。包切换方式见《TEngine引入方式与来源》。
