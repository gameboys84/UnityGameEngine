# 测试与演示指南

更新：2026-10-26。包含 2026-10-12 历史基线及本轮包化后的实际回归；后者见末节。

## 基础专项界面

从 `Assets/Launcher/Scenes/Launcher.unity` 点击 Play，进入 Main 后可使用四个测试入口。测试界面使用 GameCore 的 `UIWindow` 和 `ShowUIAsyncAwait`，预制体通过 YooAsset 加载。测试逻辑位于 `Assets/Scripts/Hotfix/Runtime/Logic/UI`，不混入 TEngine 或 GameCore 共用模块。

| 入口 | 操作 | 验证接口及可见结果 |
| --- | --- | --- |
| RESOURCE | 加载文本、生成对象、释放对象、查看包信息 | `ResourceReference.LoadAsync<TextAsset>`、`LoadGameObjectAsync`；读取真实包内容，出现第二个薄荷绿方块，释放后消失 |
| SCENE | 加载附加场景、卸载、查询场景状态 | `Scene.LoadSceneAsync(Additive)`、`UnloadAsync`、`IsContainScene`；舞台增加珊瑚色物件，卸载后消失，Main 保持活动 |
| LOCAL SAVE | 保存、读取、保存后读回、查看保存位置 | `LocalSave.SaveAsync/LoadAsync`；显示读回的数值和 UTC 时间，使用独立文件 `framework-demo.json`，不会写入业务存档 |
| TIMER | 启动、暂停、恢复、取消 | `Timer.AddTimer/Stop/Resume/RemoveTimer`；每秒增加回调次数，暂停/取消后停止增长 |

每个主测试窗口都可点击 CHILD WINDOW，异步打开一个 Top 层窗口并传递来源信息；关闭子窗口后返回原窗口。CLOSE 通过 `UIModule.CloseUI` 关闭当前窗口。操作过程中暂时禁用按钮，防止重复加载；结果和异常直接显示在结果区域。读取存档前需先保存；模块在缺少文件时返回 default，当前演示窗口可能显示一般错误，尚需补首次启动/缺失/损坏等明确结果提示。

当前 Resource/Scene/Save/Timer/Details 分别使用独立的 `*Test.prefab`，共用生成模板移到 Assets/Editor/Templates。后续的 HUD、SLG 常见界面、模态、Tips、跑马灯和批量测试说明见下文“SLG 假数据与批量工作负载”。

关闭测试窗口时清理其资源实例和计时器；附加场景由场景测试窗口持有，关闭时自动卸载。等待资源/存档时使用窗口销毁取消令牌；不可取消的场景加载若在窗口销毁后完成，会补做卸载。

启动配置 `Assets/Launcher/Settings/StartupSettings.asset` 的 `Preview Stage Seconds` 默认 0.4 秒。资源初始化、版本检查、清单更新、文件准备、预加载及进入游戏各保留最小展示时间，实际操作较慢时不叠加延迟。设为 0 可关闭。默认仅在 Editor 生效；`Preview Delays In Player` 可显式启用玩家模式展示延迟。

主场景采用深蓝舞台、薄荷绿方块、珊瑚橙圆柱和紫色球体，配合暖色主光、冷色补光与柔和阴影。场景、材质和窗口预制体均可直接在 Unity 中调整。

`TEngine/Demo/Apply Presentation and Test Panels` 是演示内容生成/更新工具，会重建 Main 的演示 UI 和测试窗口预制体，不应用于已有业务界面。`TEngine/Demo/Open Resource Lab (Play)` 可在进入 Main 后从编辑器菜单打开资源测试界面。

## SLG 假数据与批量工作负载

本轮建立独立 UI 资产、层级与批量测试。仅模拟客户端交互，数据为本次会话假数据，没有支付、真实公会服务或聊天服务器。

### 入口与独立资产

在 Launcher 点击 Play；Editor 直接运行 Main 也会先走 Launcher。进入后保留原四个基础测试按钮，下方新增角色、背包、公会、活动、商城、邮件、聊天入口，上方有 LIST、POOL、MODAL、TIPS、NEWS。

独立预制体位于 `Assets/AssetBundle/UI/SLG`。七个功能窗口分别对应 Role/Bag/Guild/Events/Shop/Mail/Chat.prefab。基础 Resource/Scene/Save/Timer/Details 也分别使用 `Assets/AssetBundle/UI/*Test.prefab`。共用编辑器生成模板位于 `Assets/Editor/Templates`，不作为运行时共享窗口加载。

同一行单元 ListRow.prefab 可在多个列表中复用；这是共用组件，不把所有功能界面放到一个运行预制体中。窗口布局可分别修改，通用组件和展示绑定逻辑共用。

### UI 层级

| 层级 | 资产/类型 | 输入与生命周期 |
| --- | --- | --- |
| Bottom | Hud.prefab / SlgHudWindow | 基础资源显示、功能导航，进入 Main 后异步打开 |
| UI | 七类功能窗口、ListBenchmark、PoolBenchmark 和基础测试窗口 | 常规弹窗；SLG 导航切换时关闭上一个选中的功能窗口；下方 HUD 导航保持可用 |
| Top | Confirm.prefab / ConfirmWindow | 全屏透明遮罩拦截下层点击；等待确认/取消结果；关闭、取消或父调用销毁结束等待 |
| Tips | Tips.prefab / TipsWindow | 连续向上飘字、淡出、实例池复用，最多 6 条同时显示；不拦截点击 |
| Tips | Marquee.prefab / MarqueeWindow | 横向消息 FIFO 队列，最多待播 40 条；RectMask2D 裁切；不拦截点击 |

HUD、Tips 和 Marquee 使用各自窗口和预制体，由 GameCore UIModule 加载。模态通过 UniTask 返回响应，避免业务逻辑在用户决定之前继续执行。这里只允许一个待响应确认窗口，新的并发确认会明确报错；尚未提供自动排队的通用模态服务。

### 假数据功能

- 角色：等级、战力展示和演示升级。
- 背包：批量物品、品质、数量展示，点击行选择。
- 公会：成员/职级/贡献列表和本地捐献反馈。
- 活动：进度与奖励样例。
- 商城：选择报价，等待模态确认，使用假金币购买；无真实付款。
- 邮件：奖励列表，领取增加假金币，同一邮件不能重复领取。
- 聊天：本地消息追加，输入长度限制；无联网。

每次进入游戏重置 FakeSlgState。列表按索引惰性生成显示数据，100,000 条逻辑数据不表示分配 100,000 个完整业务模型；当前用于验证绑定、滚动和实例规模。

### LIST：大型列表与实例速度

可选择 1,000、10,000、100,000 条数据。固定行高竖向虚拟列表只创建视口所需单元和缓冲；滚动时归还离开视口的实例并重新绑定进入视口的数据。UI 显示数据量、当前可见实例数、累计创建数。

固定行高虚拟列表位于 GameCore/UIModule/Extensions/VirtualizedScrollList，实例管理使用 GameCore/ResourceModule/PrefabInstancePool。该封装调用 TEngine 的 SingleSpawn 对象池；Prefab 的 YooAsset 引用由调用方持有，先清理实例池，再释放源资源。

“RAW CREATE / DESTROY”批量创建 UI 行并销毁；“POOL COLD / WARM”执行首次取用/归还和重复取用/归还。实际实例量限制在 5,000，防止选择 100,000 数据后误创建十万对象；界面会显示上限。分批每 100 个实例让出一帧，完成后等待销毁帧。

报告显示创建/绑定 CPU 操作累计耗时、归还/销毁请求耗时、墙钟总耗时、创建/复用/存活数量。CPU 操作计时不等于 UI Mesh 构建、渲染或 GPU 时间；墙钟时间包含分批等待、帧更新和其他 Editor 工作。缓存池保留内存直到清理/关闭，这是池化策略，不视为自动泄漏。

### POOL：大量资源与 3D 实例

数量可选 100、1,000、5,000。RAW 通过 TEngine 资源接口异步加载/实例化，再销毁；POOL 持有一次 Prefab 资源引用，通过 TEngine 实例池运行首次创建和重复取还。对象在场景中批量摆放，显示创建/复用/活跃计数。

“READ 256 DISTINCT ASSETS”依次读取 `Assets/AssetBundle/Stress` 的 256 个不同文本资源，每个约 4 KB，读完释放引用。它验证大量资源地址与引用生命周期，不代表大贴图/大模型峰值内存测试。后续需要另做真实素材分级测试。

“CLEAR POOL”清理缓存，下一次池化测试从冷实例池开始。当前显示的首轮耗时受资源和 shader 等缓存状态影响；不能把界面数值直接视为跨设备性能结论，也不承诺池化在所有场景都更快。

### 生成与验证

菜单 `TEngine/Demo/Create Independent SLG Test Assets` 生成/更新独立窗口、行 Prefab 和假资源，调整 Main 的演示入口；它会覆盖生成的 SLG 预制体布局，已有人工定制界面不应随意重新生成。
