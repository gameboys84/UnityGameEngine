# Original DeadEmpire protocol and production transport

Source: `E:/TAP/DE/DeadEmpire-DEV`, Unity 2018.4.36f1, client 0.69.0, protocol Ver/RunVer 72 at import. The source project is read-only.

`Legacy/` retains the original generated ProtocolDefine0-5, ProtocolCreator, ProtocolMVC and ProtocolTypeEnum files byte-for-byte, including their original `.meta` GUIDs. SPack, NetworkSerialization, NetworkMessage and Pike are also unchanged source imports. `Legacy/LZ4` retains its original BSD-style notices. Source DE files have no additional license grant inferred by this migration; ownership and original terms remain unchanged.

`LegacyCompatibility.cs` implements the original two-method IStubNetworkMessage contract without importing unrelated InjectFix/game/UI dependencies, and a minimal transport-codec logging adapter. It does not install a hotfix runtime or native SDK. `DeWireCodec` wraps the unchanged generated codecs. It preserves source 2-byte/extended 4-byte lengths, 2-byte node and type, signed source Pike-key derivation, independent continuous directional ciphers and both LZ4 wrapper formats. The transport validates bounded frame/compressed lengths, serializes writes and reads complete fragmented/coalesced frames.

`ProductionHttpBootstrap` performs the original development startup GET followed by HTTPS auth addresses taken only from its response. TCP gateways come from startup AddrList, never the authorization gate_ip/gate_port fields. `DeProductionConnection` uses a dedicated `de-rewrite-test-*` identity, keeps credentials/JWT in memory, does not read or overwrite original account files, and emits sanitized lifecycle diagnostics. No login body, JWT, session key or original player payload is logged.

HTTP parity review: source LoginMgr.RequestWSAuthorizePoll assigns UTF8 JSON to BestHTTP RawData; that branch does not set Content-Type (the octet-stream default is only in its UploadStream branch). The new implementation therefore uses ByteArrayContent only for POST/raw data, leaves GET Content null, and preserves source User-Agent BestHTTP, gzip/identity negotiation and keep-alive/TE headers. The dev-only handler disables inherited environment proxies and enables gzip decoding. ProductionDiagnostics.HttpAttempts contains only phase, endpoint index, attempt number, method, HTTP status, elapsed time, safe exception type chain and categorized TLS/DNS/connect/timeout outcome. It stores neither endpoint URLs nor exception messages, request bodies, JWTs or session keys. LastHttpSummary exposes the latest sanitized result.

After an observed real development auth TLS failure, the original Boot.cs UNITY_EDITOR certificate allowance is adapted as a scoped per-handler policy. Compatibility code is compiled only under UNITY_EDITOR, requires the fixed dev bootstrap and dedicated de-rewrite-test-* identity, and accepts only this session's validated startup authentication authorities (exact host and port). It requires an actual certificate and never accepts RemoteCertificateNotAvailable. Only chain/name errors are compatible. Other hosts and Player retain strict TLS, and no ServicePointManager/global callback or legacy protocol override is used. Diagnostics record policy, SslPolicyErrors flags, validation/compatibility/rejection counts and safe decisions, without certificate private material or credentials. A TLS failure before the callback remains NotObserved with zero validation count, explicitly distinguishing it from an exercised certificate decision.

The original GetVersionKey non-UNITY_ANDROID Editor branch uses IOS; 0.69.0 maps to 6900 via `(major*1000+minor)*100+patch`. Source Editor login channel is debugChanelId(0)+APP_PUBLISH_AREA_W(0). Android uses its own original bundle/platform key if explicitly selected by the caller.

The current increment stops after verified real LOGIN_ACK and remains in LoginAck. It does not create a gameplay-loading coordinator or enter a city. No client countdown/ACK invents authoritative state. Full generated typed messages, including early TIME_NTF, are buffered and dispatched through Pump. Unknown type bodies are retained instead of silently discarded. RawState is raw ingress, not a claim that all original module reducers or UI dependencies are migrated. Duplicate Begin calls cannot tear down an established login. Source HTTP status errors rotate authentication endpoints without repeating the same host; transport failures retain the original bounded retries. Internal HTTP timeout and explicit caller cancellation have distinct visible outcomes.

Known remaining integration boundaries: original account binding/role switching, independent chat SDK connection, all gameplay reducers, original UI/3D dependency closure, update channels, native platform services and device builds. Development endpoint availability and valid server configuration are external prerequisites. Standard HTTPS validation remains the Player/other-host default; the old Editor's unconditional certificate bypass is never globally copied.

Previous `Infrastructure/Resources/DE/Legacy/LegacyProtocol.json` is a source-analysis artifact, not the wire codec: its old extractor omitted initialized fields. Production serialization always uses the complete generated source.
